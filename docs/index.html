Intent is all you need

aloop is a kernel for your harness.

Your harness is the hardware. aloop is the kernel: its gates decide what is accepted, modules plug in the checks your project needs, and a distro (software: the TDD loop) is the user space you run and change. You give one line of intent; cheap workers build it, test first, in isolated worktrees.

Deterministic hooks

Models explore. Gates decide.

Give the agent something to make false. A test written after the code proves the code does what the code does. A test written before it proves the code is missing, so "done" becomes a claim a gate can check, not a sentence a model can say. A gate that crashes blocks; a BLOCK is never downgraded to a warning.

Audit

Every commit walks back to your intent.

Harness · kernel · modules · distros (M12)

Build your own Module.

Think of it as a computer. The harness (Claude Code, Codex, OpenCode, DeepSeek Harness) is the hardware. aloop is the kernel: the gate engine, its gates and the audit log, never overridden. Modules plug into the kernel: use an existing one, or build one for what your project needs. Above them runs a distro: the user space (agents, prompts, skills) that shapes the loop, yours to eject and change in git. The software distro, the TDD loop, ships today.

user space · fully overridable
  • A distro = modules + agents + skills; software (TDD) by default
  • Agents, prompts and skills, ejected on the first run
  • Layers: home > repo > plugin, per file

~/.aloop/modules/no-todo
# 1. scaffold a module: module.json + an executable check
$ aloop module new no-todo --on Stop
created ~/.aloop/modules/no-todo

# module.json
{"name": "no-todo", "on": ["Stop"],
 "command": "./check", "timeout": 120}

# check: exit 2 blocks, stderr is the reason
grep -rn TODO "$ALOOP_PROJECT/src" && {
  echo "TODO left in src/" >&2; exit 2; }
exit 0
your project
# 2. add it: its sha256 goes in distro.json, in git
$ aloop module add no-todo
added no-todo 0b4d8588bc1c

# 3. shape the loop: eject the distro's user space, edit, apply
$ aloop userspace eject
ejected 78 file(s) into docs/agents/userspace
$ aloop userspace apply

# 4. or bundle modules + user space as a distro
$ aloop distro new my-distro
$ aloop distro install ./my-distro

# at the sprint's stop, beside the core gates
◆ module no-todo blocked: TODO left in src/

Every command above ran as shown. A check sees ALOOP_EVENT, ALOOP_ROLE, ALOOP_PROJECT, ALOOP_DISTRO and ALOOP_MODULE; a crash, a timeout, or a module missing or changed since it was added blocks too, and every run is a module.run audit event.
