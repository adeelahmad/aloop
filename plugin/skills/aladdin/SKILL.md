# aladdin — the same loop, the product name

`/aladdin` is `/aloop`. Load and follow the **aloop** skill (`skills/aloop/SKILL.md`) exactly:
you are the supervisor; plan with the human in two gated stages, then dispatch one
worktree-isolated worker per task through RED → SCAFFOLD → GREEN → review → final gate.
Nothing here changes a rule, a gate or a budget; the names `aloop`, `aladdin` and `agentic`
address one system.

The intent the human gave with `/aladdin "<intent>"` (or recorded with `aladdin "<intent>"`,
see `docs/agents/intents/`) is the raw request `intake` turns into the Intent Contract.
